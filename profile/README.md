## Projetos selecionados

### [Verzel Store — QA Web e API](https://github.com/Yezzirz/verzel-store-qa-challenge)
Desafio técnico com testes funcionais, cenários negativos e de limite, Postman, evidências e dois registros de defeito. Automação de cenários críticos com **Playwright e JavaScript**, Page Objects, Gherkin como especificação e execução no GitHub Actions.

### [SauceDemo QA Suite](https://github.com/Yezzirz/Saucedemo-QA-Suite)
Projeto de estudo com plano, casos e relatório no **TestLink**, além de testes E2E com **Cypress e TypeScript**, Page Object Model e GitHub Actions. A execução manual documentada de 22/07/2026 registra 12 casos: 11 aprovados e um reprovado.

### [SauceDemo — Robot Framework](https://github.com/Yezzirz/saucedemo-robot-framework-suite)
Automação de autenticação, catálogo e checkout com **Robot Framework e SeleniumLibrary**, em ambiente Python. Recursos e dados reutilizáveis, cenários smoke e relatórios nativos/xUnit em CI.

### [YezCoins](https://yezcoins.com)
Projeto pessoal em desenvolvimento com **React, TypeScript, Supabase/PostgreSQL e Cloudflare Workers**. Prática com integração, autenticação, migrações e testes com Vitest, Testing Library e Playwright. Desenvolvimento e QA assistidos por IA, com revisão e validação. Código privado; demonstração pública.
